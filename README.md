# FPGA_END — 提交工程说明

本目录是已完成的 `p4_3_6x_auto_exposure_v11` 工程的独立提交副本。目标器件为安路 PH1P35MDG324；摄像头为 SC500CS，当前配置为 **1280×720、约 60 帧/秒、MIPI CSI-2 RAW10**，经 FPGA 处理后由 HDMI 显示。TD 工程内部名称 `camera_to_dsi_display` 保持原样，以维护现有工程和构建脚本的引用。

## 功能与操作

- 上电默认 RAW 原图、B0 亮度；显示安路 Logo、模式及状态、采集与输出帧率、1280×720 尺寸、视频缓冲及采集到显示的延迟指标。
- **KEY3 单击**依次切换 `RAW → GRAY → BIN → EDGE → CARTOON → INVERT → RAW`；**KEY3 双击**切换 `DETECT ON/OFF`。开启检测后，对红、蓝、黄、绿四种颜色及矩形（含正方形）、三角形两类形状进行单目标识别，并叠加颜色框、标签与中心坐标。圆形及不确定形状不输出形状标签。
- **KEY1 单击**沿当前方向切换七档亮度（B−3 至 B+3），**双击**仅反转升降方向。B−3 至 B0 的摄像头模拟增益目标为 6×，B+1 至 B+3 为 7×；RAW 模式另有逐像素显示亮度映射。亮度显示处理不参与颜色识别输入。
- **KEY2 单击**切换越线分类计数，**双击**清零八类计数。只有 `DETECT ON` 且目标稳定识别、沿画面从左向右完成越线时，才给对应颜色与形状的计数加一。检查线默认 `x=800`，有效区域 `y=140…620`；实际传送带安装后应将机架上的固定标记与显示线对齐。每类计数最多 999。计数开启时左侧显示八类列表，原 RGB 诊断框隐藏。
- **KEY4 单击**切换三帧差运动检测，并叠加运动区域框；**KEY4 双击**切换自动曝光，显示 `AE ON/OFF`。自动曝光从显示调亮前的 RGB 流按 16×16 间隔取样，每 8 帧根据高光/暗部统计调整传感器曝光；极暗时可请求 7× 增益。AE 开启时暂停 KEY1 改档，关闭后恢复曝光基线和已记忆的亮度档位。

系统当前按**单个主要彩色目标**定位与分类；越线计数要求目标间存在可分离的空帧间隔。运动检测为独立模块，可同时显示多个运动区域。显示端画质、识别效果与光照条件有关，现场演示以实际上板画面为准。

## 验证与重建

在本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_p4_3_sim.ps1
powershell -ExecutionPolicy Bypass -File .\build_p4_3.ps1
```

脚本依赖本机安装的 ModelSim 与 TD 6.2.1，其可执行文件路径写在脚本开头。重新构建会覆盖 `release/FPGA_END.bit`；在提交位流已经验证且无需修改源码时，直接使用现有位流即可。
